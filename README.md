# Village Kitchen

Village Kitchen is a food ordering website built with Next.js and TypeScript. The project focuses on presenting dishes, guiding customers through the menu, and creating a smooth digital experience for a local restaurant or kitchen brand.

## Highlights

- Responsive food ordering website
- Clean menu and restaurant presentation
- Mobile-friendly layout for customers browsing on phones
- Live deployment for easy client review

## Live Demo

https://village-kitchen-lac.vercel.app

## Tech Stack

- Next.js
- TypeScript
- React
- Modern CSS frontend styling
- Vercel

## Run Locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000` in your browser.

## Project Focus

This project shows how a restaurant can move from a simple online presence to a more practical ordering-style experience with clear navigation, strong presentation, and a client-friendly frontend foundation.
